# LinguaFlix

اپلیکیشن بومی اندروید برای یادگیری انگلیسی با دیالوگ‌های آموزشی و زیرنویس‌های شخصی.

## اجرا و ساخت

- Android Studio با پشتیبانی AGP 9.1، JDK 17 یا بالاتر (JBR همراه Android Studio مناسب است).
- Android SDK Platform 36 و Build Tools 36؛ حداقل گوشی Android 8 / API 26.
- پروژه را از همین پوشه باز کنید. مسیر SDK در `local.properties` محلی است و نباید در مخزن منتشر شود.
- اجرای ساخت: `./gradlew :app:assembleDebug`
- اجرای تست واحد: `./gradlew :app:testDebugUnitTest`
- تست دستگاه/شبیه‌ساز: `./gradlew :app:connectedDebugAndroidTest`
- خروجی APK: `app/build/outputs/apk/debug/app-debug.apk`، فقط پس از Build موفق.

## امکانات

- Compose، Material 3، رابط فارسی راست‌چین، تم روشن/تاریک/سیستم، اندازه متن قابل تنظیم.
- معرفی اولیه، انتخاب سطح A1 تا C2، هدف روزانه، تنظیم لهجه و صدا.
- خانه، جستجوی محلی، دسته‌بندی، کتابخانه، علاقه‌مندی، ادامه درس، تکمیل درس.
- واردکردن SRT با انتخاب‌گر سیستم، UTF-8، زمان‌بندی میلی‌ثانیه، مرتب‌سازی دیالوگ‌ها، متن چندخطی و حذف تگ‌ها؛ حداکثر ۴ مگابایت و ۱۵ هزار دیالوگ.
- انتخاب چند دیالوگ و حرکت میان انتخاب‌ها، ویرایش متن و حذف آموزش کش‌شده هنگام ویرایش.
- ترجمه، لغت، تلفظ، مثال، مترادف، گرامر، اصطلاح و مکالمه در بخش‌های باز و بسته‌شونده.
- پنج نوع تمرین با بازخورد و ثبت پاسخ صحیح و اشتباه در Room.
- ذخیره لغت، جستجو، علامت دشوار، مرور با فاصله ساده.
- آمار واقعی درس، لغت، تمرین، دقت، زمان مطالعه و هدف روزانه.
- Room برای درس، دیالوگ و آموزش کش‌شده، لغت، پاسخ تمرین و نشست مطالعه؛ DataStore برای تنظیمات.
- پاک‌کردن کش آموزشی و حذف اطلاعات محلی با تأیید داخل برنامه.

## Demo و API

چهار دیالوگ ساختگی با آموزش فارسی از پیش آماده وجود دارد؛ محتوای Demo واضح برچسب می‌خورد. فایل `samples/demo.srt` برای آزمایش واردکردن زیرنویس موجود است. آموزش متن دلخواه در Demo تولید نمی‌شود و نیاز به API صریحاً نمایش داده می‌شود.

در Debug، تنظیمات ← اتصال API ویژه توسعه را باز کنید. نشانی کامل HTTPS سازگار با `chat/completions`، نام مدل و کلید شخصی را وارد کنید. متن دیالوگ و پرسش برای ارائه‌دهنده انتخابی ارسال می‌شود. درخواست Bearer و پاسخ `choices[0].message.content` پشتیبانی می‌شود. پاسخ آموزشی باید JSON با فیلدهای `translation`, `literal`, `context`, `words`, `grammar`, `idioms`, `conversation`, `exercises` باشد. نمونه ساختار در `domain/Teaching.kt` و دستور تولید آن در `data/AiService.kt` قرار دارد.

کلید فقط در حافظه نشست نگهداری می‌شود، در فایل، DataStore، سورس یا BuildConfig ذخیره نشده و پس از پایان فرایند باید دوباره وارد شود. رابط تنظیم کلید در Release غیرفعال است. برای انتشار نهایی متصل به AI، کلید سرویس باید در یک واسط امن سمت سرور نگهداری و احراز هویت و محدودیت نرخ آنجا اعمال شود؛ این پروژه طبق درخواست هیچ بک‌اندی ایجاد نمی‌کند.

خطای شبکه، timeout، 401/403، 429 و پاسخ ساختاری نامعتبر مدیریت می‌شوند. درخواست شکست‌خورده خودکار تکرار نمی‌شود. کش به سطح آموزشی وابسته است و هنگام اتصال/قطع API پاک می‌شود.

## محدودیت‌های مشخص

- جستجو فقط در محتوای محلی است؛ کاتالوگ آنلاین فیلم و دانلود زیرنویس/ویدئو ندارد.
- TTS به موتور و صدای انگلیسی دستگاه وابسته است؛ فایل صوتی یا ویدئوی فیلم در پروژه نیست.
- معنی کلمه‌هایی که در واژه‌نامه درس نیستند از معلم درخواست می‌شود؛ فرهنگ لغت جامع آفلاین ندارد.
- ترجمه نوشتاری با پاسخ نمونه و نرمال‌سازی فاصله، حروف و علامت پایان مقایسه می‌شود؛ ارزیابی معنایی ترجمه‌های جایگزین پیاده‌سازی نشده است.
- زمان مطالعه هنگام فعال بودن صفحه آموزش ثبت می‌شود؛ زیر یک ثانیه ثبت نمی‌شود.
- الگوریتم مرور لغات ساده است و جایگزین الگوریتم تخصصی FSRS نیست.
- Demo سطح را در راهنمای تمرین لحاظ می‌کند؛ محتوای کامل شخصی‌سازی‌شده به مدل متصل وابسته است.
- صحت زبانی پاسخ AI باید توسط کاربر بررسی شود. اتصال واقعی بدون کلید/سرویس ارائه‌شده تست نشده است.

## ساختار

`data/`: Room، DataStore، Repository و HTTP AI Service.
`domain/`: پردازش SRT، مدل پاسخ آموزشی، محتوای نمونه و مقایسه پاسخ.
`ui/`: ViewModel و صفحات Compose. عملیات فایل/شبکه در IO و پردازش SRT در Default انجام می‌شوند؛ ذخیره محلی با DAOهای suspend و transaction.
`app/src/test/`: آزمون‌های parser، محتوا، پاسخ و اعتبارسنجی.
`app/src/androidTest/`: آزمون ماندگاری Room، حذف آبشاری و DataStore.
